# Project 1: Operating System

A small operating-system simulator for the COMP2040 group project. It models process scheduling, synchronization, paging, disk scheduling, and related kernel behavior.

## Project files

- [`ossim/`](ossim/) - simulator source, tests, workloads, and build files
- [`ossim/README.md`](ossim/README.md) - implementation overview, build commands, and current project scope
- [`COMP2040_Project_2026 (2).pdf`](COMP2040_Project_2026%20%282%29.pdf) - project brief

## Quick start

```sh
cd ossim
make
make test
```
